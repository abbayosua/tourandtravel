# Suggested Commands

- Lokal: XAMPP Apache+MySQL, `http://localhost/tourandtravel` (BASE_URL di `includes/config.php`).
- DB: `mysql -u root tourandtravel < database/schema.sql` → `php database/seeder.php` → `php database/seed-layanan.php` (opsional: `seed-hotels-extra.php`, `seed-flight-schedules.php`); wiki: `php database/fetch-wiki-images.php`.
- Git: `git status`, `git diff`, `git log --oneline -10`; jangan commit tanpa diminta.
- Validasi memori: `serena memories check` di project root.

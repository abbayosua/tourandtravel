## Sisa Backlog (kerja konten/lanjutan, tidak memblokir fitur)

1. **String hardcoded non-t()** — beberapa teks statis tidak melewati `t()`:
   footer (Kontak, Jam Operasional, alamat), aria-label/data-attribute, string
   di `<script>` config JSON. Perlu refactor bertahap kalau mau 100% zh.
2. **Konten DB bahasa zh** — FAQ & blog dari DB masih `content_language='id'`
   (tampil fallback). Isi manual via admin atau tambah seed.
3. **Kolom `_zh` tabel lain** — hanya posts/hotels/hotel_rooms yang punya kolom
   `_zh`. Tabel tours dsb mengandalkan `content_language` + tabel `translations`
   (desain saat ini memang begitu).
4. **Test e2e regex rot (pre-existing)** — update regex
   `/Cari Booking|Masukkan kode booking/` di `abuse-sqli.spec.ts` &
   `abuse-xss.spec.ts` agar mengenal `查询订单`;
   kredensial admin lokal untuk `local-auth.spec.ts`.
5. **Android app** — `MainActivity.java` BASE_URL sudah benar; jika ingin
   push zh otomatis, kirim `lang` saat register FCM token dari app
   (endpoint sudah support).
6. **Terjemahan email subject default** — subject fallback
   `ucfirst(event)` masih English (di `renderEmailTemplate`); bisa ditambah
   map subject per-lang bila dibutuhkan.
